# Dataset placement

Download each dataset from its linked Kaggle page, then extract the CSV into this directory:

- Email Spam Classification: emails.csv
- Uber Fares: uber.csv

The notebooks expect these exact paths:

- Data/emails.csv
- Data/uber.csv

The CSVs are excluded from Git because they are source datasets. The Email Spam file contains pre-tokenized word-frequency features and a Prediction column.
